- QRIS JACK STORE ID untuk pembayaran
- Upload & preview bukti pembayaran
- Notifikasi sukses + reset form otomatis

### Admin Dashboard

- LocalStorage untuk persistensi data
- Font: Poppins (Google Fonts)
- Fully responsive (mobile & desktop)
